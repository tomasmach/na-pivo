# Na pivo invite assets

Final exports:

- `og-invite.png` — 1200 × 630 Open Graph preview.
- `favicon.ico` — 16, 32, 48 and 64 px favicon bundle.
- `favicon-512.png` — flat-color favicon source/export.
- `apple-touch-icon.png` — 180 × 180 touch icon.

The OG illustration was generated with the built-in image generation tool using
`assets/images/onboarding/slide-parta.png` as the style reference. Prompt summary:
three Czech dimpled mugs clinking, wide right-heavy composition, hand-drawn
linocut/screenprint texture, dark espresso background, amber beer and warm cream
foam, no text, logos, gradients, glow, 3D or extra objects.

The base artwork was remapped to exactly three flat brand colors (`#201006`,
`#F2A900`, `#FFF1D6`), then the final social copy and exact 1200 × 630 layout
were added deterministically with the bundled Baloo 2 fonts. Text edges retain
normal raster anti-aliasing; there are no tonal gradients, glows or shadows. The
favicon was derived from the existing app icon and remapped to the flat palette.
